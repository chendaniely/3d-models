# Where issues live

This repo has no issue tracker of its own, and GitHub Issues are off for agent work.

- **A finding deferred during a phase** goes on the plan's phase-end list, at the bottom of
  `docs/superpowers/plans/<date>-3d-models-phase-N.md`: its source task, severity, file and status.
- **Something that waits past this phase** goes in the spec's *Later* table,
  `docs/superpowers/specs/2026-11-05-3d-models-design.md`, with the reason it waits.
- **Something with a date, or someone waiting on it,** is proposed to Dan as a ticket in his
  YouTrack, never filed silently.

A reviewer reading this for the spec axis: the spec and the phase's plan are the source of what was
asked for.
